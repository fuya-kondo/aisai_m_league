# 麻雀成績管理サイト

内部利用向けの麻雀成績管理Webアプリです。
スマホ利用を前提に、対局結果の登録、成績確認、履歴確認、AI分析をシンプルに行える構成になっています。

## アプリ概要

- 成績の登録、修正、削除
- 全体成績、個人成績の確認
- 成績履歴の確認
- AIによる傾向分析
- 管理画面からのマスターデータ運用

## 開発環境

- バックエンド: PHP
- フロントエンド: JavaScript, HTML, CSS
- データベース: MySQL
